## 🧪 選定決定(4 ステップ)

### Step 1 · 流体タイプ
- **液体** → 液体フィルター(FILTER PLUS)
- **気体(浄化)** → 気体フィルター(WALKER)
- **気体(除湿)** → 気体ドライヤー(WALKER)

### Step 2 · ろ過精度
| 精度要件 | 選定 |
|---------|------|
| 0.1~1 μm(高純度) | 液体フィルター PP/PES カートリッジ |
| 1~50 μm(一般工業) | 液体フィルター バッグ式 |
| 50~200 μm(粗ろ過) | 液体フィルター 大流量バッグ |
| 0.01~1 μm(半導体級) | 気体フィルター HEPA 級 |
| 1~5 μm(一般圧縮空気) | 気体フィルター 標準級 |

### Step 3 · 流量 / 処理量
プロセス流量に応じてカートリッジ数量とハウジングサイズを選定、弓海が条件に応じて推奨します。

### Step 4 · 特殊要件
- **衛生級**(食品/製薬)→ SUS316L 研磨
- **防爆** → ATEX 認証
- **高温** → メタルハウジング

## ❓ よくある質問

<details>
<summary><b>Q1:ろ過精度の選び方は?</b></summary>

下流機器に応じて選定:圧縮空気の pneumatic 機器向け → 1~5 μm;シリンダー向け → 5~25 μm;半導体プロセス → 0.01~0.1 μm(HEPA/ULPA 級)。
</details>

<details>
<summary><b>Q2:液体フィルターのカートリッジ交換頻度は?</b></summary>

条件次第:一般工業用水 1~3 ヶ月;高固体化学 2~4 週;食品/製薬は GMP バリデーションサイクル準拠。弓海がカートリッジ寿命予測を提供可能。
</details>

<details>
<summary><b>Q3:冷凍式と吸着式ドライヤーの選択は?</b></summary>

**冷凍式**:露点 +2°C ~ +10°C、通常工業ガス、省エネ;**吸着式**:露点 -40°C ~ -70°C、半導体/製薬/精密計装。一般工業は冷凍式、高露点要求は吸着式。
</details>
