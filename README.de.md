## 🧪 Auswahlentscheidung (4 Schritte)

### Schritt 1 · Mediumtyp
- **Flüssigkeit** → Flüssigkeitsfilter (FILTER PLUS)
- **Gas (Reinigung)** → Gasfilter (WALKER)
- **Gas (Entfeuchtung)** → Gastrockner (WALKER)

### Schritt 2 · Filtergenauigkeit
| Genauigkeitsanforderung | Auswahl |
|---------------|---------|
| 0.1~1 μm (hohe Reinheit) | Flüssigkeitsfilter PP/PES-Kartusche |
| 1~50 μm (allgemeine Industrie) | Flüssigkeitsfilter Beuteltyp |
| 50~200 μm (grob) | Flüssigkeitsfilter Hochdurchsatzbeutel |
| 0.01~1 μm (Halbleitergrad) | Gasfilter HEPA-Grad |
| 1~5 μm (allgemeine Druckluft) | Gasfilter Standardgrad |

### Schritt 3 · Durchsatz / Kapazität
Wählen Sie Kartuschenanzahl und Gehäusegröße nach Prozessdurchsatz; Gonghai kann basierend auf Ihren Bedingungen empfehlen.

### Schritt 4 · Besondere Anforderungen
- **Sanitär** (Lebensmittel/Pharma) → SUS316L poliert
- **Explosionsgeschützt** → ATEX-zertifiziert
- **Hochtemperatur** → Metallgehäuse

## ❓ FAQ

<details>
<summary><b>F1: Wie wählt man die Filtergenauigkeit?</b></summary>

Basierend auf den Anforderungen der nachgelagerten Geräte: Druckluft für pneumatische Elemente → 1~5 μm; für Zylinder → 5~25 μm; Halbleiterprozess → 0.01~0.1 μm (HEPA/ULPA-Grad).
</details>

<details>
<summary><b>F2: Wie oft müssen Flüssigkeitsfilterkartuschen ausgetauscht werden?</b></summary>

Abhängig von den Bedingungen: allgemeines Industriewasser 1~3 Monate; Chemie mit hohem Feststoffgehalt 2~4 Wochen; Lebensmittel/Pharma gemäß GMP-Validierungszyklus. Gonghai kann Kartuschenlebensdauer vorhersagen.
</details>

<details>
<summary><b>F3: Kältetrockner oder Adsorptionstrockner?</b></summary>

**Kältetrocknung**: Taupunkt +2°C ~ +10°C, normales Industriegas, energiesparend; **Adsorption**: Taupunkt -40°C ~ -70°C, Halbleiter/Pharma/Präzisionsinstrumente. Reguläre Industrie → Kältetrocknung; hohe Taupunkte → Adsorption.
</details>
