## 🧪 Selection Decision (4 Steps)

### Step 1 · Media Type
- **Liquid** → Liquid Filter (FILTER PLUS)
- **Gas (purification)** → Gas Filter (WALKER)
- **Gas (dehumidify)** → Gas Dryer (WALKER)

### Step 2 · Filtration Precision
| Precision Need | Selection |
|---------------|-----------|
| 0.1~1 μm (high purity) | Liquid filter PP/PES cartridge |
| 1~50 μm (general industrial) | Liquid filter bag type |
| 50~200 μm (coarse) | Liquid filter high-flow bag |
| 0.01~1 μm (semiconductor) | Gas filter HEPA grade |
| 1~5 μm (general compressed air) | Gas filter standard grade |

### Step 3 · Flow / Capacity
Select cartridge quantity and housing size based on process flow; Gonghai can recommend based on your conditions.

### Step 4 · Special Requirements
- **Sanitary** (food/pharma) → SUS316L polished
- **Explosion-proof** → ATEX certified
- **High temperature** → Metal housing

## ❓ FAQ

<details>
<summary><b>Q1: How to choose filtration precision?</b></summary>

Based on downstream equipment requirements: compressed air for pneumatic elements → 1~5 μm; cylinders → 5~25 μm; semiconductor process → 0.01~0.1 μm (HEPA/ULPA grade).
</details>

<details>
<summary><b>Q2: How often to replace liquid filter cartridges?</b></summary>

Depends on conditions: general industrial water 1~3 months; high-solids chemicals 2~4 weeks; food/pharma per GMP validation cycle. Gonghai can provide cartridge life estimation.
</details>

<details>
<summary><b>Q3: Refrigeration vs adsorption dryer?</b></summary>

**Refrigeration**: Dew Point +2°C ~ +10°C, regular industrial gas, energy-saving; **Adsorption**: Dew Point -40°C ~ -70°C, semiconductor/pharma/precision instruments. Regular industry → refrigeration; high dew point requirement → adsorption.
</details>
