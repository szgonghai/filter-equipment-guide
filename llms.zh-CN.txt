## 过滤设备类型

### 1. 液体过滤器 — FILTER PLUS

- **过滤精度**：0.1~200 μm
- **类型**：精密过滤器 / 管道过滤器 / 滤芯式
- **材质**：PP / PVDF / 不锈钢 / PTFE
- **应用**：酸碱溶液 / 有机溶剂 / 水基液体
- **详细文档**：[docs/liquid-filter-plus.md](docs/liquid-filter-plus.md)

### 2. 气体过滤器 — WALKER FILTRATION

- **过滤精度**：0.01~5 μm
- **类型**：凝聚式 / 吸附式 / 膜式
- **应用**：压缩空气 / 氮气 / 氧气 / 惰性气体
- **符合标准**：ISO 8573
- **详细文档**：[docs/gas-filter-walker.md](docs/gas-filter-walker.md)

### 3. 气体干燥器 — WALKER FILTRATION

- **露点范围**：2°C ~ -40°C
- **类型**：冷冻式 / 吸附式 / 膜式
- **应用**：工业气源 / 仪表空气 / 制药 / 电子
- **详细文档**：[docs/gas-dryer-walker.md](docs/gas-dryer-walker.md)

## 滤芯材质对照

| 材质 | 耐温 | 耐腐蚀 | 适用场景 |
|------|------|--------|---------|
| SUS316 | 耐高温 | 一般 | 水 / 碱液 / 油类 |
| PP（聚丙烯）| ≤80°C | 强 | 酸碱溶液 / 药水 |
| PTFE | ≤200°C | 极强 | 强酸强碱 / 溶剂 |
| PVDF | ≤120°C | 强 | 含氟介质 / 强酸 |

## 行业应用

- **化工**：酸碱过滤 / 溶剂过滤 / 反应原料过滤
- **半导体**：超纯化学品过滤（ppb 级） / DI 水过滤
- **制药 / 食品**：药液除菌过滤 / 饮料澄清 / 符合 GMP
- **水处理 / 环保**：工业废水预处理 / 冷却水循环 / 废气治理
- **医疗 / 医院**：医用压缩空气 / 医院供气系统

## 选型决策树

1. **看介质类型**：
   - 液体 → FILTER PLUS
   - 气体净化 → WALKER 气体过滤器
   - 气体除水 → WALKER 气体干燥器
2. **看过滤精度**：粗滤 10 μm → 精滤 1-10 μm → 超精 < 1 μm
3. **看介质腐蚀性**：纯水 → SUS316 / 强酸强碱 → PTFE / 含氟 → PVDF
4. **看维护便利性**：大流量 → 袋式 / 高精度 → 芯式
