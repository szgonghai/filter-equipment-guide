## 🧪 选型决策（4 步走）

### Step 1 · 介质类型
- **液体** → 液体过滤器（FILTER PLUS）
- **气体（需净化）** → 气体过滤器（WALKER）
- **气体（需除水）** → 气体干燥器（WALKER）

### Step 2 · 过滤精度
| 精度需求 | 选型 |
|---------|------|
| 0.1~1 μm（高纯度） | 液体过滤器 PP/PES 滤芯 |
| 1~50 μm（一般工业） | 液体过滤器 滤袋式 |
| 50~200 μm（粗过滤） | 液体过滤器 大流量滤袋 |
| 0.01~1 μm（半导体级） | 气体过滤器 HEPA 级 |
| 1~5 μm（一般压缩空气） | 气体过滤器 标准级 |

### Step 3 · 流量 / 处理量
按工艺流量选滤芯数量与壳体尺寸，弓海可按工况推荐。

### Step 4 · 特殊要求
- **卫生级**（食品/制药）→ SUS316L 抛光
- **防爆** → ATEX 认证
- **高温** → 金属壳体

## ❓ 常见问题

<details>
<summary><b>Q1：过滤精度怎么选？</b></summary>

按下游设备要求选：压缩空气后端用气动元件 → 1~5 μm；后端用气缸 → 5~25 μm；半导体工艺 → 0.01~0.1 μm（HEPA/ULPA 级）。
</details>

<details>
<summary><b>Q2：液体过滤器多久换一次滤芯？</b></summary>

取决于工况：一般工业水处理 1~3 个月；化工高固含量 2~4 周；食品/制药按 GMP 验证周期。弓海可提供滤芯寿命预估。
</details>

<details>
<summary><b>Q3：如何选择冷冻式还是吸附式干燥器？</b></summary>

**冷冻式**：露点 +2°C ~ +10°C，常规工业气源，节能；**吸附式**：露点 -40°C ~ -70°C，半导体/制药/精密仪表。普通工业选冷冻式，要求高露点选吸附式。
</details>
