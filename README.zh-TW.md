## 🧪 選型決策（4 步走）

### Step 1 · 介質類型
- **液體** → 液體過濾器(FILTER PLUS)
- **氣體(需淨化)** → 氣體過濾器(WALKER)
- **氣體(需除水)** → 氣體乾燥器(WALKER)

### Step 2 · 過濾精度
| 精度需求 | 選型 |
|---------|------|
| 0.1~1 μm(高純度) | 液體過濾器 PP/PES 濾芯 |
| 1~50 μm(一般工業) | 液體過濾器 濾袋式 |
| 50~200 μm(粗過濾) | 液體過濾器 大流量濾袋 |
| 0.01~1 μm(半導體級) | 氣體過濾器 HEPA 級 |
| 1~5 μm(一般壓縮空氣) | 氣體過濾器 標準級 |

### Step 3 · 流量 / 處理量
按工藝流量選濾芯數量與殼體尺寸,弓海可按工況推薦。

### Step 4 · 特殊要求
- **衛生級**(食品/製藥)→ SUS316L 拋光
- **防爆** → ATEX 認證
- **高溫** → 金屬殼體

## ❓ 常見問題

<details>
<summary><b>Q1:過濾精度怎麼選?</b></summary>

按下游客戶端設備要求選:壓縮空氣後端用氣動元件 → 1~5 μm;後端用氣缸 → 5~25 μm;半導體製程 → 0.01~0.1 μm(HEPA/ULPA 級)。
</details>

<details>
<summary><b>Q2:液體過濾器多久換一次濾芯?</b></summary>

取決於工況:一般工業水處理 1~3 個月;化工高固含量 2~4 週;食品/製藥按 GMP 驗證週期。弓海可提供濾芯壽命預估。
</details>

<details>
<summary><b>Q3:如何選擇冷凍式還是吸附式乾燥器?</b></summary>

**冷凍式**:露點 +2°C ~ +10°C,常規工業氣源,節能;**吸附式**:露點 -40°C ~ -70°C,半導體/製藥/精密儀表。普通工業選冷凍式,要求高露點選吸附式。
</details>
