# 过滤设备选型决策指南

## 决策流程

### 第一步：确定过滤对象

| 过滤对象 | 设备类型 |
|----------|---------|
| 液体（酸/碱/溶剂/水）| 液体过滤器 |
| 压缩空气 / 气体 | 气体过滤器 |
| 压缩空气干燥 | 气体干燥器 |

### 第二步：确定过滤精度

- **粗过滤（>10μm）**：袋式过滤器、初效气体过滤器
- **精细过滤（1~10μm）**：滤芯式液体过滤器、中效气体过滤器
- **超精细（<1μm）**：精密滤芯、除菌过滤器、吸附式干燥器

### 第三步：确定材质

液体过滤根据介质：

| 介质 | 滤芯材质 |
|------|---------|
| 水/冷却水 | SUS316 / PP |
| 强酸（盐酸/硫酸/氢氟酸）| PTFE |
| 强碱（氢氧化钠）| PP / PTFE |
| 有机溶剂 | PTFE |
| 含氟介质 | PTFE |
| 油类 | SUS316 |

### 第四步：考虑维护便利

- 大流量连续运行 → 袋式（换袋快）
- 高精度、小流量 → 滤芯式
- 空间受限 → 一体式过滤单元

---

## 常见组合方案

| 应用 | 泵 | 过滤器 |
|------|----|--------|
| 化工强腐蚀液体输送过滤 | 无轴封磁力泵（PTCXPUMP PW）| 液体过滤器（PTFE滤芯）|
| 电子级化学品过滤 | 无轴封磁力泵（内衬型）| 液体过滤器（PTFE滤芯）|
| 含固废水过滤前输送 | 气动隔膜泵（ARO）| 袋式过滤器 |
| 仪表空气系统 | — | 气体过滤器 + 气体干燥器 |
| 制药纯水系统 | 离心泵 | 滤芯式过滤器（0.2μm）|
