## 🧪 Decisão de Seleção (4 Passos)

### Passo 1 · Tipo de Meio
- **Líquido** → Filtro de Líquido (FILTER PLUS)
- **Gás (purificação)** → Filtro de Gás (WALKER)
- **Gás (desumidificação)** → Secador de Gás (WALKER)

### Passo 2 · Precisão de Filtração
| Requisito de Precisão | Seleção |
|-----------------------|---------|
| 0.1~1 μm (alta pureza) | Filtro líquido cartucho PP/PES |
| 1~50 μm (industrial geral) | Filtro líquido tipo saco |
| 50~200 μm (grosseiro) | Filtro líquido saco de alto fluxo |
| 0.01~1 μm (nível semicondutor) | Filtro gás grau HEPA |
| 1~5 μm (ar comprimido geral) | Filtro gás grau padrão |

### Passo 3 · Vazão / Capacidade
Selecione a quantidade de cartuchos e tamanho do invólucro conforme a vazão do processo; a Gonghai pode recomendar conforme suas condições.

### Passo 4 · Requisitos Especiais
- **Sanitário** (alimentação/farmacêutica) → SUS316L polido
- **À prova de explosão** → Certificado ATEX
- **Alta temperatura** → Invólucro metálico

## ❓ Perguntas Frequentes

<details>
<summary><b>P1: Como escolher a precisão de filtração?</b></summary>

Conforme os requisitos do equipamento downstream: ar comprimido para elementos pneumáticos → 1~5 μm; para cilindros → 5~25 μm; processo de semicondutores → 0.01~0.1 μm (grau HEPA/ULPA).
</details>

<details>
<summary><b>P2: Com que frequência os cartuchos do filtro de líquido são substituídos?</b></summary>

Depende das condições: água industrial geral 1~3 meses; química com alto teor de sólidos 2~4 semanas; alimentação/farmacêutica conforme ciclo de validação GMP. A Gonghai pode estimar a vida útil do cartucho.
</details>

<details>
<summary><b>P3: Secador por refrigeração ou adsorção?</b></summary>

**Refrigeração**: Ponto de Orvalho +2°C ~ +10°C, gás industrial regular, econômico; **Adsorção**: Ponto de Orvalho -40°C ~ -70°C, semicondutores/farmacêutica/instrumentos de precisão. Indústria regular → refrigeração; alto ponto de orvalho → adsorção.
</details>
