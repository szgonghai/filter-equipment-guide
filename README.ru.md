## 液体过滤器 — FILTER PLUS

### 产品类型

- **袋式过滤器**：更换滤袋便利，适合大流量
- **滤芯式过滤器**：过滤精度高，滤芯种类多

### 滤芯材质

| 材质 | 耐温 | 耐腐蚀 | 适用场景 |
|------|------|--------|---------|
| **SUS316** | 耐高温 | 一般 | 水、碱液、油类 |
| **PP（聚丙烯）** | ≤80°C | 强 | 酸碱溶液、药水 |
| **PTFE** | ≤200°C | 极强 | 强酸强碱、溶剂 |
| **PVDF** | ≤120°C | 强 | 含氟介质、强酸 |

### 主要特点
- 多种材质滤芯可选，适配不同介质
- 滤芯精度从1μm到100μm不等
- 结构设计便于更换滤芯
- 可根据客户工况定制过滤方案

### 规格参考

| 参数 | 袋式 | 滤芯式 |
|------|------|--------|
| 过滤精度 | 1~200 μm | 0.1~100 μm |
| 最大流量 | 大流量 | 中等流量 |
| 更换方式 | 换袋 | 换芯 |
| 适用介质 | 水、油、碱液 | 酸碱、溶剂、水 |

## 气体过滤器 — WALKER FILTRATION

### 产品类型

- **压缩空气过滤器**：去除压缩空气中的油、水、颗粒
- **除尘过滤器**：去除气体中的固体颗粒
- **除菌过滤器**：去除细菌与微粒（医疗/制药级）

### 主要特点
- 适合工业和医疗应用的高品质空气过滤器
- 多种精度可选（0.01μm ~ 5μm）
- 符合ISO标准规定之纯度等级
- 各式工业用途中皆可灵活运用

### 规格参考

| 过滤精度 | 1~5 μm | 0.01~0.1 μm | 0.2 μm |
| 最高温度 | 取决于配置 | 取决于配置 | 取决于配置 |

## 气体干燥器 — WALKER FILTRATION

### 产品类型

- **冷冻式干燥器**：通过降温冷凝去除水分
- **吸附式干燥器**：通过干燥剂吸附去除水分
- **组合式干燥器**：冷冻+吸附组合

### 主要特点
- 使空气达到干燥、洁净的效果
- 符合ISO标准规定之纯度等级
- 露点温度可控（常压露点可达-40°C以下）
- 适用于工业气源、仪表空气、制药、电子等行业

### 规格参考

| 参数 | 冷冻式 | 吸附式 |
|------|--------|--------|
| 压力露点 | +3°C ~ +10°C | -20°C ~ -70°C |
| 处理量 | 大流量 | 中小流量 |
| 能耗 | 低 | 中（再生耗能）|
| 适用场景 | 一般工业 | 高洁净要求 |

## Критерии подбора

### 1. 看介质类型
- **液体过滤** → FILTER PLUS 袋式/滤芯式
- **压缩空气过滤** → WALKER FILTRATION 气体过滤器
- **压缩空气干燥** → WALKER FILTRATION 气体干燥器

### 2. 看过滤精度
- **粗过滤（>10μm）** → 袋式过滤器 / 初效过滤器
- **精细过滤（1~10μm）** → 滤芯式过滤器 / 气体过滤器
- **超精细（<1μm）** → 精密滤芯 / PTFE滤芯 / 除菌过滤器

### 3. 看介质腐蚀性
- **纯水/中性液体** → SUS316 / PP
- **强酸强碱** → PTFE / PVDF
- **含氟介质** → PTFE

### 4. 看维护便利性
- **大流量、频繁更换** → 袋式（换袋比换芯快）
- **高过滤精度要求** → 滤芯式
- **空间受限** → 考虑一体式过滤单元
