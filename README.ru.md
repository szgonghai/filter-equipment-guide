## 🧪 Принятие решения (4 шага)

### Шаг 1 · Тип среды
- **Жидкость** → Жидкостный фильтр (FILTER PLUS)
- **Газ (очистка)** → Газовый фильтр (WALKER)
- **Газ (осушка)** → Осушитель газа (WALKER)

### Шаг 2 · Точность фильтрации
| Требуемая точность | Подбор |
|-------------------|--------|
| 0.1~1 мкм (высокая чистота) | Жидкостный фильтр картридж PP/PES |
| 1~50 мкм (общая промышленность) | Жидкостный фильтр мешочного типа |
| 50~200 мкм (грубая) | Жидкостный фильтр высокопроизводительный мешок |
| 0.01~1 мкм (полупроводниковый) | Газовый фильтр класс HEPA |
| 1~5 мкм (общий сжатый воздух) | Газовый фильтр стандартного класса |

### Шаг 3 · Расход / Производительность
Выберите количество картриджей и размер корпуса по расходу процесса; Gonghai может рекомендовать по вашим условиям.

### Шаг 4 · Особые требования
- **Санитарный** (пищевая/фармацевтика) → SUS316L полированный
- **Взрывозащита** → Сертификат ATEX
- **Высокая температура** → Металлический корпус

## ❓ Часто задаваемые вопросы

<details>
<summary><b>В1: Как выбрать точность фильтрации?</b></summary>

По требованиям нижестоящего оборудования: сжатый воздух для пневмоэлементов → 1~5 мкм; для цилиндров → 5~25 мкм; полупроводниковый процесс → 0.01~0.1 мкм (класс HEPA/ULPA).
</details>

<details>
<summary><b>В2: Как часто менять картриджи жидкостного фильтра?</b></summary>

Зависит от условий: общая промышленная вода 1~3 месяца; химия с высоким содержанием твёрдых частиц 2~4 недели; пищевая/фармацевтика по циклу валидации GMP. Gonghai может оценить ресурс картриджа.
</details>

<details>
<summary><b>В3: Холодильный или адсорбционный осушитель?</b></summary>

**Холодильный**: точка росы +2°C ~ +10°C, обычный промышленный газ, экономичный; **Адсорбционный**: точка росы -40°C ~ -70°C, полупроводники/фармацевтика/прецизионные приборы. Обычная промышленность → холодильный; высокая точка росы → адсорбционный.
</details>
